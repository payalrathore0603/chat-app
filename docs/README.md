# Real-Time Chat Application

A production-oriented real-time chat application built with React and Spring Boot.

## Tech Stack

### Frontend

- React
- TypeScript
- Vite

### Backend

- Java
- Spring Boot
- Spring Security
- Spring WebSocket
- Spring Data JPA

### Database

- PostgreSQL

### Infrastructure

- Docker
- GitHub Actions

## Architecture

React → Spring Boot → PostgreSQL

WebSocket will be used for real-time messaging.
